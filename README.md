# Lab 1: การทดลองใช้ AI Coding Assistant 

Repository นี้เป็นส่วนหนึ่งของการส่งงาน Lab 1 จัดทำขึ้นเพื่อทดลองรันโค้ด Python เบื้องต้นและประเมินความสามารถของ AI ในการช่วยเขียน ตรวจสอบ และอธิบายโค้ด (ครอบคลุม Sub-CLO 1.4: ทดลองใช้ AI coding assistant และระบุข้อควรระวัง)

## 🎯 วัตถุประสงค์
* ทดลองรันและทดสอบโค้ด Python ผ่าน Google Colab
* ใช้ AI ช่วยค้นหาข้อผิดพลาด (Bug) และอธิบายการทำงานของโค้ด
* เรียนรู้ขีดจำกัดของ AI ผ่านการทดสอบ Edge case (เช่น กรณีข้อมูลว่างเปล่า)
* ทำความเข้าใจและประเมินระดับการพึ่งพา AI (Trust Level 1-5) ตามความเหมาะสมของงาน

## 📂 ไฟล์ใน Repository นี้
* `(ชื่อไฟล์ของคุณ).py`: ไฟล์โค้ด Python ที่รวมฟังก์ชันใหม่ที่ให้ AI เขียนขึ้นและผ่านการทดสอบ (Test case) เรียบร้อยแล้ว
* `ai-experiment.md`: ไฟล์บันทึกผลการทดลอง ซึ่งประกอบด้วย:
  * บันทึกการหา Bug ของ AI และกรณีที่ AI อาจมองข้าม
  * การประเมิน AI Trust Level พร้อมเหตุผล
  * บันทึกการอธิบายโค้ดโดย AI และการประเมินความถูกต้อง

## 🔬 สรุปผลการเรียนรู้ที่สำคัญ (Key Takeaways)
1. **AI อาจมองข้ามจุดสำคัญ:** จากการทดลองให้ AI หา Bug ในฟังก์ชันคำนวณเกรด พบว่า AI อาจไม่แจ้งเตือนกรณีข้อบกพร่องที่ร้ายแรง (เช่น การคำนวณค่าเฉลี่ยจากลิสต์ที่ไม่มีคะแนนอยู่เลย `[]` ซึ่งทำให้เกิด Error อาการโปรแกรมพัง)
2. **โปรแกรมเมอร์คือผู้รับผิดชอบหลัก:** AI เป็นเพียงผู้ช่วย (Assistant) ไม่ใช่ผู้รับผิดชอบงาน การนำโค้ดจาก AI มาใช้จำเป็นต้องมีการทดสอบ (Test) โดยมนุษย์เสมอ
3. **การใช้ AI ให้เหมาะสมกับ Trust Level:** การตัดสินใจว่าจะพึ่งพา AI ในระดับใด (1-5) ไม่ได้วัดจากว่า AI เขียนโค้ดเก่งแค่ไหน แต่วัดจาก "ความเสี่ยง" ของงานนั้นๆ หากงานมีความสำคัญหรือเสียหายหนักเมื่อเกิดข้อผิดพลาด ควรเลือกใช้ Trust Level ระดับต่ำที่มนุษย์มีส่วนร่วมในการตัดสินใจมากที่สุด
